# Security Policy

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/EnricoDev1/tecnoctl/security/advisories/new). Do not open a public issue before a fix is available.

Include the affected version, impact, and reproduction steps. Never include real alarm credentials, public endpoints, or personal alarm data.

This project is experimental and should not be used as the only alarm notification channel or exposed directly to the Internet.
